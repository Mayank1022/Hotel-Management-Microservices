Hotel Management System – Microservices

A simple Hotel Management System built using Spring Boot and Microservices Architecture. This project focuses on understanding how independent microservices communicate with each other using REST APIs and RestTemplate.

The main objective is to learn the fundamentals of microservices communication, service separation, API integration, and distributed application development.

 Project Objectives

Understand Microservices Architecture.

Learn service-to-service communication.

Implement synchronous communication using RestTemplate.

Understand how independent Spring Boot applications interact.

Exchange data between multiple services through REST APIs.

Practice DTOs, exception handling, and API integration.

Understand the challenges of distributed systems.
